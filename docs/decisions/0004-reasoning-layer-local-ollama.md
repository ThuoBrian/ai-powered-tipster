# 0004 — Reasoning layer: local LLM via Ollama

- **Status:** Accepted
- **Date:** 2026-09-05

## Context

Tips need explanations — the "why" behind a recommendation — and the product
brief called for "a small model trained for football reasoning". Language
models are excellent narrators of structured evidence and poor calibrated
probability estimators, so where they sit in the pipeline matters more than
which one runs.

## Decision

Reasoning is generated by a **small local LLM served through Ollama**
(Qwen-class), with numbers produced elsewhere:

- The numeric model (ADR 0003) emits probabilities, derived market prices,
  and top contributing features. This structured context is injected into the
  prompt — the LLM narrates, it never estimates.
- The LLM adds qualitative context when available (injuries, motivation,
  derby intensity) and may later extract structured features from news, but
  its output is prose plus caveats, never numbers of record.
- A deterministic template fallback renders explanations when Ollama is not
  running, so the UI never depends on the LLM being up.
- Fine-tuning on football analysis text is a v2+ milestone, not a launch
  requirement; good prompting with injected evidence covers most of the value.

## Consequences

- Free, private, offline — consistent with the local-AI stack already in use
  (Ollama-backed RAG services), and no per-call cost or key management.
- Small local models produce mediocre prose on their own; quality depends on
  tight, structured prompts, so the prompt contract is part of `tipster-core`
  and is tested.
- Ollama becomes an optional runtime dependency for that one feature only —
  everything else works without it.
- Hallucination risk is contained structurally: the numbers are never the
  LLM's to invent.
